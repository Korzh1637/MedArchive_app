# 📚 MedArchive

**MedArchive** — мобильное приложение для хранения медицинских данных и отслеживания показателей здоровья в динамике.

Приложение позволяет:

* 📁 хранить медицинские документы
* 📊 отслеживать показатели (давление, пульс, вес и др.)
* 🧠 вести персональный журнал здоровья

---

# 🚀 Быстрый старт (очень важно пройти все шаги)

## 1. 📥 Клонируем проект

```bash
git clone https://github.com/Korzh1637/MedArchive_app.git
cd MedArchive_app
```

---

## 2. 🐍 Создаем виртуальное окружение

```bash
python -m venv venv
```

Активация:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / Mac:**

```bash
source venv/bin/activate
```

---

## 3. 📦 Устанавливаем зависимости

```bash
pip install -r requirements.txt
```

---

## 4. 🌐 Узнаем IP своего компьютера

Это нужно, чтобы приложение на телефоне смогло подключиться к серверу.

```bash
ipconfig
```

👉 Найди строку типа:

```
IPv4 Address . . . . . . . . . . : 192.168.0.105
```

📌 Запомни этот IP — он понадобится в приложении.

---

## 5. 🖥️ Запускаем backend (сервер)

```bash
uvicorn database.FastAPI.api:app --reload --host 0.0.0.0 --port 8000
```

После запуска сервер будет доступен по адресу:

```
http://<ТВОЙ_IP>:8000
```

Пример:

```
http://192.168.0.105:8000
```

---

## 6. 📱 Запуск приложения

Установи файл:

```
MedArchive.apk
```

на свой Android телефон.

---

## 7. 🔗 Подключение к серверу

⚠️ ВАЖНО:
Телефон и компьютер должны быть **в одной Wi-Fi сети**

В приложении укажи:

```
http://<ТВОЙ_IP>:8000
```
